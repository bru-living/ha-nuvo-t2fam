# Contributing

Bug reports and focused pull requests are welcome.

When reporting a tuner or connection problem, include:

- Home Assistant version
- Integration version
- TCP bridge model or local serial adapter model
- Selected tuner (A or B)
- Downloaded integration diagnostics
- Relevant debug log lines with credentials or public addresses removed

Keep the integration scoped to one configurable tuner on an NV-T2FAM, FM only, in standalone operation without NuVoNet.

Before opening a pull request, ensure Python files parse, JSON files are valid, and the protocol tests pass.
